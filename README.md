# Wi-Fi Router Antenna – CST Analysis

## Project Overview

This project focuses on the reverse engineering and electromagnetic analysis of a Wi-Fi router antenna using CST Microwave Studio.

## Objective

- To study the structure and working of an existing Wi-Fi router antenna.
- To model and analyse the antenna using CST Microwave Studio.
- To investigate dual-band operation at 2.45 GHz and 5 GHz.
- To analyse important antenna parameters and electromagnetic characteristics.

## Software Used

- CST Microwave Studio

## Antenna

- Antenna Type: Monopole
- Operating Frequencies: 2.45 GHz
- Conducting Material: Copper

## Parameters Analysed

- S11
- VSWR
- Gain
- Directivity
- Efficiency
- Radiation Pattern
- Surface Current Distribution
